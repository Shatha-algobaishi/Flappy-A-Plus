# Flappy A+ 🎮

A **Flappy Bird-inspired 2D arcade game** developed with **Unity and C#**. Guide a flying A+ character through pairs of pipes, earn points by passing obstacles, and try to beat your previous score.

## Gameplay

- Keep the **A+ character** flying and navigate through gaps between pipes.
- Earn **one point** for each pipe obstacle successfully passed.
- Avoid hitting the pipes or falling off the playable area.
- When the game ends, see the **Game Over** screen and select **Play Again** to retry.

## Features

- 2D obstacle-avoidance gameplay
- Pipe movement and spawning
- Collision and falling-based game-over conditions
- Score tracking
- Restart option after losing
- In-game audio

## Built With

- **Unity** — 2D game engine
- **C#** — gameplay scripting

## Run the Project

1. Clone or download this repository.
2. Open **Unity Hub** and choose **Add project from disk**.
3. Select the downloaded project folder (the one containing `Assets`, `Packages`, and `ProjectSettings`).
4. Open the project with a compatible Unity Editor version (see `ProjectSettings/ProjectVersion.txt`).
5. Open the game scene from the `Assets/Scenes` folder and press **Play** in the Unity Editor.

> Unity may take a few minutes to import project assets and regenerate its local cache the first time you open it.
